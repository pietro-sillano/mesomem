Run an example

MesoMem ships with LAMMPS as pair_style mesomem/dipole in the DIPOLE package, with OpenMP and Kokkos (GPU) versions. No custom build is needed. Run the inputs from the examples folder, since each one reads its data file from there:

cd examples
mpirun -np 4 lmp -in in.planar

Inputs

  • in.planar Flat membrane of 2125 particles across the periodic box. After equilibration at constant area, a barostat relaxes it to zero tension. Reports the projected area.
  • in.vesicle Spherical vesicle of 2000 particles with radius 10.88. Reports the radius of gyration.
  • in.selfassembly 1500 particles that grow from small aggregates into flat membrane patches. Reports the number of clusters, the largest cluster and free particles. Same files as in the LAMMPS distribution.

Parameters

Each input sets the model parameters as index variables at the top. Override them from the command line:

lmp -in in.vesicle -var ktilt 12.0 -var T 0.25
VariableMeaningDefault
epsDepth of the isotropic potential minimum1.0
rcutCutoff of the isotropic potential2.5
ktiltTilt stiffness15.0
ksplaySplay stiffness1.0
wcCutoff of the tilt and splay energies (wc ≤ rcut)2.0
zetaWidth of the attractive branch; sets the in-plane diffusivity5.0
c0Spontaneous curvature0.0
TTemperature of the Langevin thermostat0.2

To write a trajectory, uncomment the dump lines in an input. View it in OVITO, showing the dipoles as membrane normals.
